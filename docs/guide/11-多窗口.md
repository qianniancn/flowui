# 11 · 多窗口

单窗口用 `Run` / `RunProgram` 即可。需要多个独立窗口时，用 **`ui.Application`**。

## 概念

| 概念 | 说明 |
|------|------|
| `Application` | 多窗口宿主 |
| `WindowSpec` | 一个窗口的规格（key、初始化、Update、View、选项） |
| 窗口 key | 字符串身份，用于 Open / Close / SetTheme |
| `OpenResult` | `OpenStarted` / `OpenRaised` / `OpenRejected` |

每个窗口有**独立 Model 实例**；初始化函数按实例执行，不要共享可变 Model。

## 基本结构

```go
func main() {
	var application ui.Application

	counter := ui.NewWindow("counter",
		func() CounterModel { return CounterModel{} },
		counterUpdate,
		counterView(&application),
		ui.Title("Counter"),
		ui.Size(400, 300),
	)

	mainWin := ui.NewWindow("main",
		func() MainModel { return MainModel{} },
		mainUpdate(&application),
		mainView(&application, counter),
		ui.Title("Main"),
		ui.Size(640, 480),
	)

	application.Run(mainWin)
}
```

也可用 `ui.NewProgramWindow` 挂完整 `Program`（Init / Cmd / Subscriptions）。

固定集合一次跑多个：

```go
ui.RunWindows(winA, winB)
```

## 打开与关闭

```go
result := application.Open(counterSpec)
switch result {
case ui.OpenStarted:
	// 新建并运行
case ui.OpenRaised:
	// 同 key 已存在，前置
case ui.OpenRejected:
	// 策略拒绝
}

application.Close("counter")
```

在主窗口按钮里：

```go
ui.Button("open", ui.Text("打开计数器")).OnClick(func() {
	application.Open(counter)
})
```

## 主题与语言（按窗口）

```go
application.SetTheme("main", ui.DarkTheme())
application.SetLanguage("main", ui.LanguageChinese)
```

在对应窗口的 Update 中根据消息调用（见 `examples/multi_windows`）。
不要在任意 goroutine 里直接改主题；走 Application API，以便在目标窗口事件循环上应用。

## 窗口状态

在 View 中：

```go
state := ctx.WindowState()
// state.Size, state.Mode, state.Focused, ...
```

也可用 `Program.WindowStateMessage` 把配置变化转成 Msg。

窗口动作（最小化/最大化等）见示例中的 `WindowAction*` 用法。

## 注意

1. **key 唯一**：同一 Application 内窗口 key 不要冲突。
2. **Model 独立**：`func() M { return M{} }` 每次 Open 新建。
3. **不要跨窗口直接改对方 Model**；用消息、共享服务或 Application 协调。
4. **Cmd 的 context** 随该窗口生命周期取消。

## 示例

```bash
go run ./examples/multi_windows
```
