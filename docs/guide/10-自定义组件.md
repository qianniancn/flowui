# 10 · 自定义组件

扩展只有三条合法路径。**默认走路径 A**；不要先去抄官方 Button 源码。

## 路径 A — 声明式组合（首选）

用官方积木 + `Box` + `Style` + 回调：

```go
func Tag(key, text string, selected bool, onToggle func()) ui.Widget {
	return ui.Box(ui.Text(text)).
		Key(key).
		Label(text).
		Style(
			ui.PaddingX(12).PaddingY(6).Radius(999).
				Background(ui.TokenSurfaceSecondary).
				Cursor(ui.CursorPointer).
				When(ui.Hovered, ui.Background(ui.TokenSurfaceTertiary)).
				When(ui.If(selected),
					ui.Background(ui.TokenAccent).
						TextColor(ui.TokenAccentForeground),
				).
				When(ui.Pressed, ui.Scale(0.98, 0.98)),
		).
		OnClick(onToggle)
}
```

在 View 里：

```go
Tag("tag-go", "Go", m.Selected, func() {
	send(ToggleTag{})
})
```

| 关注点 | 用法 |
|--------|------|
| 外观 | `Style` + `When` + Token |
| 交互 | `Key` + `OnClick` / `Disabled` / `Label` |
| 结构 | `Row` / `Column` / 官方控件 |
| 业务 | 回调 → `send` |

**目标：80% 以上自定义停在这里。**

## 路径 B — 复合组件协议（与官方同构）

需要多 Part、variant/size、领域 props 时，走与 Button 相同的装配：

```text
BeginInteract → Resolve / ResolvePart → LayoutInteractiveBox（或 LayoutBox）
```

示意（与 `examples/custom_widgets` 一致）：

```go
type customTrigger struct {
	key     string
	label   string
	pressed bool
	onClick func()
	style   ui.Style
}

func (b customTrigger) Layout(ctx *ui.Context, gtx layout.Context) layout.Dimensions {
	ix := ui.BeginInteract(ctx, gtx, b.key, ui.InteractOpts{
		OnClick:  b.onClick,
		Label:    b.label,
		Selected: b.pressed,
	})

	defaults := ui.Width(190).Height(36).PaddingX(12).Radius(6).
		Background(ui.TokenSurfaceSecondary).
		Cursor(ui.CursorPointer).
		Part(ui.PartLabel, ui.FontSize(13)).
		When(ui.Hovered, ui.Background(ui.TokenSurfaceTertiary)).
		When(ui.FocusVisible, ui.Outline(2, 1, ui.TokenFocus))

	// 四槽：defaults, variant, size, instance
	resolved := ui.Resolve(ctx, gtx, b.key, ix.StyleState,
		defaults, ui.Style{}, ui.Style{}, b.style)
	label := ui.ResolvePart(ctx, gtx, b.key, ui.PartLabel, ix.StyleState,
		defaults, ui.Style{}, ui.Style{}, b.style)

	content := ui.WidgetFunc(func(ctx *ui.Context, gtx layout.Context) layout.Dimensions {
		return ui.LayoutBox(ctx, gtx, label, ui.Text(b.label))
	})
	return ui.LayoutInteractiveBox(ctx, gtx, resolved, content, ix.Host)
}
```

要点：

1. 值类型 + fluent 配置
2. 实现 `ui.Widget`
3. 交互只来自 `BeginInteract`
4. 样式四槽：defaults · variant · size · instance（+ StyleScope）
5. 外壳只经 Host；不私建边框栈
6. 回调只 `send`，不改 Model
7. 焦点：`ix.Clickable` + `ctx.RequestFocus` / `FocusVisible`

完整可运行代码：`examples/custom_widgets`。

## 路径 C — 画布自绘

在 **Host 内容区** 内画领域像素（图表曲线、特殊可视化）：

```go
ui.Canvas(func(gtx layout.Context, size image.Point) {
	// 使用 Gio op 绘制；不要在这里重做卡片边框/阴影外壳
})
```

规则：

- 外壳（margin/padding/背景/圆角/阴影）仍归 Style + Host
- Canvas 只负责**内容**
- 需要点击态时，外层仍用路径 A/B 包一层交互

见 `ui/canvas.go` 与相关测试/示例。

## 反模式

| 不要 | 原因 |
|------|------|
| import `internal/components/...` | 破坏封装，升级即碎 |
| 在组件里保存业务 Model | 状态双源 |
| 无 Key 却依赖 hover 保留 | 槽位不保留 |
| 组件内第二套盒模型 API | 与 Style 冲突 |
| 教用户「复制 Button 源码改」 | 应走公开协议 |

## UseState

`ui.UseState` / `UseStateWith` 仅用于**瞬态交互**（例如某手势中间量），且依赖显式 Key。
业务数据仍放 Model。
