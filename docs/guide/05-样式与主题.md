# 05 · 样式与主题

## Style 是什么

`style.Style` 是**不可变**的外观与盒模型声明。从零值起头，再链式方法叠加：

下文示例统一假定已通过 `activeTheme := core.ActiveTheme(ctx)` 取得当前主题值，
颜色**直接引用主题的 `Palette` 字段**（主题是值，不是查询——见 [architecture](../architecture.md)）：

```go
primary := style.New().Background(style.Solid(activeTheme.Palette.Accent)).
	TextColor(style.Solid(activeTheme.Palette.AccentForeground)).
	Radius(8).
	PaddingX(12).PaddingY(6).
	Cursor(style.CursorPointer)
```

挂到控件：

```go
button.New("确定").Style(primary)
// 或
layout.Box(child).Style(style.New().Padding(24))
// 需要拆开写时，一次调用接收多条声明（按顺序合并，后者覆盖前者）
layout.Box(child).Style(style.New().Padding(24), style.New().MaxWidth(760))
```

不必为每个属性写一次 `.Style(...)`：链式声明能放进同一次调用，多条声明也能一次传入。重复调用 `.Style(...)` 同样累积（`layout.Box` 走 `style.Join`）。

没有单独的 Builder / Build 步骤；每次方法返回新的 Style 值。

## 级联顺序（固定）

```text
组件 defaults
  → 继承文本（父级 Text 声明）
  → variant
  → size
  → resolve.Scope 祖先
  → 实例 Style
  → Cascade(When) → Transitions
```

**后写的同名属性在同一层内覆盖先写的**；`When` 在运行时按状态叠加。

## On：状态样式

```go
primary := style.New().Background(style.Solid(activeTheme.Palette.Accent)).
	TextColor(style.Solid(activeTheme.Palette.AccentForeground)).
	Radius(8).
	Cursor(style.CursorPointer).
	On(style.Hovered, style.New().Background(style.Solid(activeTheme.Palette.AccentHover))).
	On(style.Pressed, style.New().Background(style.Solid(activeTheme.Palette.AccentPressed)).Scale(0.96)).
	On(style.Disabled, style.New().Opacity(0.5))
```

常见状态位：`style.Hovered`、`Pressed`、`FocusVisible`、`Disabled`、`Checked`、`Selected`、`Invalid`、`Loading` 等，可用 `|` 组合（如 `OnAny(style.Hovered|style.Focused, ...)`）。

把 **Model 布尔值** 接进同一条路径——声明每帧由 View 重建，条件直接折叠进构造：

```go
if model.Highlighted {
	primary = primary.Background(style.Solid(activeTheme.Palette.AccentHighlight))
}
```

## 动作预设：四件套

主题内置四个动作观感预设——配色与 Hover/Pressed/Disabled 反馈一行写好，几何留给组件：

```go
// 一键获得主操作观感（Accent 配色 + 状态行 + 配色过渡）
button.New("保存").Style(activeTheme.PrimaryAction())

// 预设是值，直接链式覆盖或追加状态行
activeTheme.PrimaryAction().On(style.Loading, style.New().Opacity(0.7))
```

四件套：`PrimaryAction`（Accent 填充）、`SecondaryAction`（表面软色）、`DangerAction`
（危险填充）、`GhostAction`（透明静默）。预设取值来自语义色板，Provider 可以为按钮变体
定义不同的视觉处理；预设不含 Radius / 高度 / 内边距 / 焦点环——这些归采纳它的组件。

把**两个现成声明**合成（后者覆盖基础值、规则表拼接）用 `style.Join`；单声明上的改写
直接链式追加即可：

```go
button.New("删除").Style(style.Join(activeTheme.DangerAction(), style.New().Radius(4)))
```

## resolve.Scope：子树默认

作用域入口在 `style/resolve` 子包（`style` 本身是纯声明机制，不依赖框架，需要上下文的入口
都在它旁边），下文按 `resolve` 引用：

```go
resolve.Scope(
	style.New().FontSize(14).TextColor(style.Solid(activeTheme.Palette.Foreground)),
	layout.Column(
		text.New("继承字号与颜色"),
		button.New("保存").Style(primary),
	).Gap(8),
)
```

Scope 向下传递；**实例 Style 仍优先**。Scope 不会改全局 Theme。

## Part：复合控件零件

根 Style 作用在**外层盒子**；内部用 `Part`：

```go
barStyle := style.New().Background(style.RGBA(0x111827cc)).
	Part(style.PartTrack, style.New().Height(6).Background(style.Solid(activeTheme.Palette.SurfaceRaised))).
	Part(style.PartFill, style.New().Background(style.Solid(activeTheme.Palette.Accent))).
	Part(style.PartLabel, style.New().TextColor(style.Solid(activeTheme.Palette.MutedForeground)))

progress.Bar("upload", 42).Label("上传").Style(barStyle)
```

常见 Part：`PartContent`、`PartLabel`、`PartIcon`、`PartTrack`、`PartFill`、`PartThumb`、`PartPanel`、`PartItem`、`PartBackdrop`、`PartPlaceholder`、`PartPrefix`、`PartSuffix` 等。

字段类控件（Select、Input 组）常用 **`PartContent`** 表示字段表面。

## 颜色与主题值

颜色**直接引用主题的 `Palette` 字段**，便于明暗主题切换：

```go
style.New().Background(style.Solid(activeTheme.Palette.Surface))
style.New().TextColor(style.Solid(activeTheme.Palette.Foreground))
style.New().Background(style.Solid(activeTheme.Palette.Accent))
```

字面色与透明度：

```go
style.RGB(0x0078d4)                             // 0xRRGGBB
style.RGBA(0x00000030)                          // 0xRRGGBBAA
style.WithAlpha(activeTheme.Palette.Focus, 0.5) // 复用主题色改 alpha
```

⚠️ 主题值**在声明处求值**：不要把带主题色的 Style 缓存进 Model 字段——主题切换后
缓存的值不会更新。声明应在渲染路径上每次构造。

### 渐变与自定义绘制

自定义组件需要绘制渐变时，可以先把颜色源转成画刷，再交给公共绘制函数：

```go
brush, ok := resolve.Brush(style.LinearGradient(
	style.ColorStop(0, style.Solid(activeTheme.Palette.Accent)),
	style.ColorStop(1, style.Solid(activeTheme.Palette.Danger)),
))
if ok {
	draw.Fill(gtx, image.Rect(0, 0, 160, 32), 6, brush)
}
```

`resolve.Color` 用于取得单个具体色；`draw.FillRRect` 用于已有
`clip.RRect` 的形状。不要把渐变绘制扩展成浮层系统。

## 主题

### 启动时

默认主题入口来自 `github.com/qianniancn/flowui/theme/base`：
直接使用 `base.Light()` / `base.Dark()`，或调整种子后构造主题。
默认风格采用 Slate 灰阶、Indigo 强调色、1dp 边框和 32dp 常规控件；
明暗截图与尺寸规范见 [默认主题与外部风格](18-设计风格.md)。
`Light` / `Dark` 提供默认靛蓝；`New` / `NewDark` 使用传入的种子颜色。

```go
seed := theme.DefaultSeed()
seed.Primary = color.NRGBA{R: 0x00, G: 0x78, B: 0xd4, A: 0xff}

ui.Run(ui.NewProgram(Model{}, Update, View),
	window.Theme(base.NewDark(seed)), // 浅色使用 base.New(seed)
	// 或局部改：
	window.CustomizeTheme(func(t *theme.Theme) {
		t.Components.Input.Radius = 8
	}),
	window.Locale(window.LanguageChinese),
)
```

### 运行时（多窗口 Application）

```go
application.SetTheme("main", base.Dark())
application.SetLanguage("main", window.LanguageChinese)
```

替换会在目标窗口的事件循环中生效；接口用法见 [11-多窗口](11-多窗口.md)。

### 字体

默认主题使用 `sans-serif` 和 `monospace` 字体族，并允许 Gio 使用系统字体
回退。这样不需要额外资源就能显示不同语言；但不同系统的字形可能略有差异。
系统字体回退会建立完整的系统字体索引，启动和内存开销都可能明显增加；只需要
固定字体时，建议关闭它并提供完整的字体回退集合。

需要固定字体时，可以把字体文件随程序打包。`ParseFontCollection` 支持 TTF、OTF
和 TTC：

```go
package main

import (
	_ "embed"

	"github.com/qianniancn/flowui/style"
	"github.com/qianniancn/flowui/theme"
	"github.com/qianniancn/flowui/theme/base"
)

//go:embed fonts/Inter-Regular.ttf
var interRegular []byte

func appTheme() theme.Theme {
	faces, err := style.ParseFontCollection(interRegular)
	if err != nil {
		panic(err)
	}
	t := base.Light()
	t.Typography.Typeface = "Inter, sans-serif"
	t.Fonts.Collection = faces
	t.Fonts.SystemFonts = false
	return t
}
```

`Theme.Fonts.Collection` 应在应用启动前准备好，多个窗口可以共享解析后的字体
数据；每个窗口仍会创建自己的 Shaper。关闭系统字体后，请确保集合包含应用需要
的字符范围，必要时将多个字体集合并到同一个 `Collection`。

将上述字体配置放入自己的应用，并提供 `go:embed` 引用的字体文件。
需要分析启动与绘制开销时，可在应用中使用标准库 `runtime/pprof` 或系统进程分析器。

## 几何常用项

```go
style.New().Width(200).Height(40)
style.New().MinWidth(100).MaxWidth(400)
style.New().Padding(12)           // 或 PaddingX / PaddingY
style.New().Margin(8)
style.New().Radius(8)             // 或四角分别设置
style.New().BorderWidth(1).BorderColor(style.Solid(activeTheme.Palette.Border))
style.New().BorderBottom(1, style.Solid(activeTheme.Palette.Border))
style.New().BoxShadow(0, 6, 18, 0, style.RGBA(0x00000030))
style.New().Opacity(0.9)
style.New().Cursor(style.CursorPointer)
style.New().Overflow(style.OverflowHidden) // 裁剪溢出
```

## Transition（声明式属性动画）

```go
style.New().Background(style.Solid(activeTheme.Palette.Surface)).
	Transition(style.PropBackgroundColor, 120*time.Millisecond).
	On(style.Hovered, style.New().Background(style.Solid(activeTheme.Palette.SurfaceRaised)))
```

需要稳定 **Key**；详见 [12-动画](12-动画.md)。

## 原则小结

1. 外观与盒模型 → Style
2. 排列策略 → 布局容器
3. 状态外观 → `When`，不要为 hover 另建一棵 UI 树
4. 主题色 → 直接引用 `Palette` 值，少写死 RGB

## 实例样式与主题默认外观

`.Style(...)` 是**实例级**覆盖；控件在没有实例样式时的默认外观由主题 provider 决定（`theme/<x>style` 配方 + `Components.*` token），行为与布局在 `widget/*` 里，不关心具体色值。

```go
// 实例覆盖：只影响这一个按钮
button.New("保存").Style(primary).Variant(button.Primary)

// 主题默认外观：换 provider 即整体换肤，控件代码不变
type Brand struct{ base.Provider }

func (Brand) Button(active *theme.Theme, request theme.ButtonRequest) theme.ButtonVisual {
	visual := buttonstyle.BuildButton(active, request, buttonstyle.DefaultConfig())
	visual.Variant = visual.Variant.Radius(10) // 示例：改默认圆角
	return visual
}

active := base.Light()
active.VisualProvider = Brand{}
```

规则：**能被单个实例覆盖的放 `.Style(...)`；一套主题对所有实例生效的放 provider 配方 / `Components.*` token**。
