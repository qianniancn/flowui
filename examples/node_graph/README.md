# Node Graph Example

Run with:

```powershell
go run ./examples/node_graph
```

The example is split into six tabs:

- `Editing`: controlled node and edge changes, snapping, selection, connection, and reconnection.
- `Create nodes`: application-owned node creation from the command panel or canvas double-click, controlled deletion, and dynamic connections.
- `Relational data`: a small relational schema with table fields, primary keys, foreign keys, and editable relationships.
- `Groups`: parent-local child coordinates, parent bounds, typed ports, and eight-way resizing.
- `Overlays`: fixed canvas panels, viewport overlays, node toolbars, and edge toolbars.
- `Large graph`: a 12 by 12 graph using viewport culling and the NodeGraph spatial index.
