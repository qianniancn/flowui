# Lucide icon index

A searchable contact sheet for all 1,899 Lucide icons exported by
`github.com/qianniancn/flowui-icons-lucide`.

Current catalog: module **v0.4.0**, Lucide **1.60.0**.

```text
go run ./examples/lucide_icons
```

## What it demonstrates

- A controlled search field with token matching: `arrow left` finds `ArrowLeft`.
- A responsive, virtualized grid, so all icons are available without laying out
  every tile each frame.
- Alphabet filtering for browsing without a query.
- Selection state with a larger preview and the matching Go identifier.
- An empty-result state that clears the active filters.

## Catalog generation

The icon module exports each icon as an individual value and does not ship a
runtime catalog. `catalog_gen.go` is generated by scanning those declarations:

```text
go generate ./examples/lucide_icons
```

The generator reads the installed module version, so updating the Lucide module
and re-running `go generate` refreshes both the catalog and its version comment.
